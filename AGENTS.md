# Indian Market Skills

Before you write or review code for Indian tax, transaction charges, NSE/BSE market data, broker statements, backtests, options or broker APIs, read the matching `skills/<name>/SKILL.md`. The index is in [README.md](README.md#skills). Each skill's frontmatter `description` says when to use it.
For a review, follow the checklist in `reviewers/<name>.md` and report findings in the format that file gives.
If you are contributing to this repo, read [CLAUDE.md](CLAUDE.md) and [CONTRIBUTING.md](CONTRIBUTING.md).
